# منصة الطالب الذكي العراقي 🇮🇶

منصة تعليمية متكاملة لطلاب السادس الإعدادي في العراق، مبنية بـ Vanilla JavaScript و Firebase مع واجهة عصرية Dark Mode و بوابة اشتراك تليگرام.

## خطوات التشغيل والنشر على Vercel:
1. قم بفك ضغط هذا الملف.
2. تأكد أن ملف `firebase-config.js` يحتوي على مفاتيح مشروعك الحقيقية.
3. ارفع الملفات إلى مستودع على GitHub.
4. اذهب إلى [Vercel](https://vercel.com/) وانشئ مشروعاً جديداً بربطه بمستودع GitHub.
5. اضغط Deploy وسيكون موقعك أونلاين بالكامل!
